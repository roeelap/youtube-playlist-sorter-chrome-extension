# YouTube Playlist Sorter

A Chrome extension that sorts YouTube playlists alphabetically and adds a search bar to the "Save to playlist" dropdown.

## What it does

- **Sorts playlists alphabetically** — When you click "Save" on a video and choose a playlist, the dropdown list is sorted A–Z.
- **Search/filter bar** — Quickly find playlists by typing in the dropdown.

## Installation

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (toggle in the top-right)
3. Click **Load unpacked**
4. Select this extension folder

## Usage

1. Go to any YouTube video
2. Click **Save** under the video
3. The "Save to playlist" dropdown will show your playlists sorted alphabetically with a search bar
